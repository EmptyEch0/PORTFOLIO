# AweFill — Intelligent Form Autofill & Learning Extension

<div className="text-zinc-400 text-sm mb-8 font-serif">
  Persona Case Study • Chrome Extension (Manifest V3) • Zero-LLM Deterministic Matching Engine
</div>

<div className="space-y-8 text-[15.5px] text-zinc-300 leading-relaxed font-serif">

<p>
  <strong className="text-zinc-100 font-medium">AweFill</strong> is an intelligent, air-gapped browser extension built with React 19, TypeScript, and Chrome Manifest V3. </p>

<p>

</p>

<ul className="space-y-2 text-zinc-300 pl-4 list-disc">
  <li>
    <strong className="text-zinc-200">Exhausting Manual Re-Entry:</strong> Entering identical contact details, graduation years, GPA, addresses, work histories, and portfolio URLs 50+ times across different ATS systems.
  </li>
  <li>
    <strong className="text-zinc-200">The Flaw of Standard Autofillers:</strong> Traditional browser autofill only handles basic fields (name and email) and breaks completely on complex job questionnaires or dropdowns.
  </li>
  <li>
    <strong className="text-zinc-200">Why LLMs Are the Wrong Tool for Autofill:</strong> Cloud LLM-based autofillers take 2–5 seconds per page, cost money on every API call, and leak sensitive identity records to third-party AI APIs.
  </li>
</ul>
