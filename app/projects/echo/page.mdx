# Echo — AI Communication Copilot

<div className="text-zinc-400 text-sm mb-8 font-serif">
  Persona Case Study • Chrome Extension (Manifest V3) • Privacy-First NLP & Local Memory
</div>

<div className="space-y-8 text-[15.5px] text-zinc-300 leading-relaxed font-serif">

<p>
  <strong className="text-zinc-100 font-medium">Echo</strong> is a smart browser extension (an AI communication copilot) that integrates directly into your web messaging apps to help you reply to chats faster <em>while sounding authentically like you</em>, eliminating the robotic, stiff tone typical of standard AI chatbots.
</p>

<h2 className="font-cormorant text-2xl text-zinc-100 font-semibold pt-4 mb-2">1. The Problem: Why Standard AI Fails in Messaging</h2>

<p>
  Most people communicating across professional and informal channels face two major frictions:
</p>

<ul className="space-y-2 text-zinc-300 pl-4 list-disc">
  <li>
    <strong className="text-zinc-200">The "Robotic AI" Syndrome:</strong> Standard cloud models generate verbose, overly formal paragraphs ("I hope this message finds you in good health") that sound completely unnatural in instant messaging.
  </li>
  <li>
    <strong className="text-zinc-200">Context Switching Overhead:</strong> Copy-pasting conversation snippets back and forth into ChatGPT browser tabs breaks conversation flow and takes more time than typing manually.
  </li>
  <li>
    <strong className="text-zinc-200">Privacy & Data Leakage:</strong> Sending personal and professional chat histories to third-party cloud servers introduces significant privacy risks.
  </li>
</ul>

<h2 className="font-cormorant text-2xl text-zinc-100 font-semibold pt-4 mb-2">2. Supported Messaging Platforms</h2>

  <li><strong className="text-zinc-200">WhatsApp Web</strong> (web.whatsapp.com)</li>
  <li><strong className="text-zinc-200">Instagram Direct Messages</strong> (instagram.com/direct)</li>
  <li><strong className="text-zinc-200">Telegram Web</strong> (web.telegram.org)</li>
  <li><strong className="text-zinc-200">Discord Web</strong> (discord.com/app)</li>
  <li><strong className="text-zinc-200">X (Twitter) DMs</strong> (x.com/messages)</li>
</ul>

<h2 className="font-cormorant text-2xl text-zinc-100 font-semibold pt-4 mb-2">4. Technical Architecture</h2>

<p>
  Echo is architected into three distinct decoupled layers:
</p>

<ul className="space-y-3 text-zinc-300 pl-2">
  <li className="flex gap-2">
    <span className="text-zinc-500 shrink-0">1.</span>
    <div>
      <strong className="text-zinc-100">DOM Injection & UI Layer (React 18 & Manifest V3):</strong> Injects an isolated shadow root above chat input fields with zero page layout shift, mutation observers for real-time bubble detection, and keyboard shortcut listeners.
    </div>
  </li>
  <li className="flex gap-2">
    <span className="text-zinc-500 shrink-0">2.</span>
    <div>
      <strong className="text-zinc-100">Context Analyzer & Persona Brain (Python FastAPI / NVIDIA NIM):</strong> Extracts multi-turn conversation context, applies style vector weighting, and generates 3 diverse response trajectories.
    </div>
  </li>
  <li className="flex gap-2">
    <span className="text-zinc-500 shrink-0">3.</span>
    <div>
      <strong className="text-zinc-100">Local Memory Engine (IndexedDB & Chrome Storage):</strong> Tracks frequency metrics, style preferences, and offline fallback dictionaries without sending data to external databases.
    </div>
  </li>
</ul>
