## ✨ Portfolio Architecture & Key Features

This repository contains the source code for my personal digital garden and portfolio, built from the ground up for performance, aesthetics, and interactivity:

- **⚡ Next.js 16 + React 19 + Turbopack**: Blazing-fast page transitions, static rendering, and modern component architecture.
- **🧠 In-Browser Semantic Search & Knowledge Graph**:
  - Powered by `@xenova/transformers` for client-side neural text embeddings.
  - Hybrid search combining semantic vector cosine similarity and fuzzy keyword ranking (`fuse.js`).
  - Searchable knowledge base indexed directly in `knowledgeBase.json`.
- **🎨 Rich Visual Aesthetics & Micro-Animations**:
  - Built with Tailwind CSS v4 and Framer Motion.
  - Interactive Polaroid galleries, carousel project showcases, custom route loaders, and offline status detector.
  - Retro-modern dark theme with typography powered by Cormorant Garamond & Geist.
- **📬 Dynamic Contact Form**: Integrated via Resend API route (`/api/contact`) with floating instant-contact drawer.
- **📝 MDX-Powered Deep-Dives**: Rich storytelling for projects, career reflections, engineering philosophy, and research notes.

## 💻 Local Development

### Prerequisites
- Node.js 18.17+ or Node.js 20+
- `pnpm` (recommended), `npm`, or `yarn`

### 1. Clone the repository
```bash
git clone https://github.com/EmptyEch0/PORTFOLIO.git
cd PORTFOLIO
```

### 2. Install dependencies
```bash
pnpm install
# or
npm install
```

### 3. Setup environment variables (Optional)
Create a `.env.local` file in the project root:
```env
RESEND_API_KEY=your_resend_api_key
POSTGRES_URL=your_database_url_if_using_redirects
```

### 4. Run the development server
```bash
pnpm dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Build for production
```bash
pnpm build
# or
npm run build
```
